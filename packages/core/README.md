# pi-tee-core

Shared policy, route admission, native Pi catalog publication, request guards and response authentication for the NEAR and Tinfoil extensions. This library is not an extension and imports neither provider SDK.

`parsePolicy()` implements the four positions and forced/category rules of `PI_TEE_POLICY`. The default is `public-builds,egress=metadata`; removed names return migration guidance. `assessRoute()` checks every threshold against actual request evidence, `weakestRoute()` combines plaintext components, and `compareRoutes()` orders code, host, GPU and egress. Only B3 and S3 admission are implemented; all other build/review settings, including `build=signed`, are rejected as not yet supported. [Security model](../../docs/security-model.md).

`createTeeProvider()` exposes a native provider, discovery, session policy changes and a content-free report. Adapters supply candidate `routes`, potential levels for discovery only, and `openSession()` results with verified levels and owned transports. The core preflights the canonical model, admits candidates before sending a prompt, disposes losing sessions, snapshots public admission, and prevents dispatch after policy changes or evidence expiry. Discovery metadata never establishes security levels. Non-public dispatch requires explicit rated routes; legacy public-profile registration remains available for local integrations; custom adapters are trusted local code.

`guardChatFetch()` fixes the endpoint, model and authentication after Pi conversion/hooks and rejects unclassified fields, hosted tools and remote media. `authenticateResponse()` releases bounded body bytes only after signature verification. `pinnedTlsFetch()` checks the attested SPKI on the actual TLS 1.3 socket before writing one HTTP/1.1 request; it rejects redirects/resends and propagates cancellation under Node and Bun. [Transport](src/transport.ts), [socket binding](src/pinned-tls.ts).

`runNvidiaVerifier()` runs the hash-checked NVIDIA WebAssembly module in a cancellable worker with a bounded bridge restricted to NVIDIA reference/OCSP services. `runNrasVerifier()` authenticates NVIDIA's overall and detached per-device EAT tokens. `checkGpuAppraisal()` and `rateGpuAppraisal()` apply common authenticity, nonce, distinct-device, count, mode and firmware checks to either verdict. Complete protected setups are G1; documented authenticated gaps are G2; incomplete coverage is G3. A remote verdict alone never establishes admission. [Notices](wasm/THIRD_PARTY_LICENSES.txt).

`runWasiCommand()` gives a verified CPU helper only arguments, a fixed environment, clocks, randomness and bounded stdin/stdout, with no preopened directories or sockets. Cancellation and timeout terminate its worker. `formatProviderReport()` exposes position, actual trusts/gaps and route choice through `/nearai status` and `/tinfoil status`.

Catalog capability and SDK protocol support are separate provider claims. Unsupported protocols are hidden by default and blocked before setup; show-all labels them. Policy changes abort active requests. These guards protect provider dispatches, not the whole Pi session; independent approval and whole-session protection remain unestablished. Tested with Pi 1.0.4 and the locked dependency set.
