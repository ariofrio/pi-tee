# Verification procedures

This index separates repeatable checks from their [dated results](../evidence/README.md). Follow [CONTRIBUTING](../../CONTRIBUTING.md) and read [SECURITY](../../SECURITY.md) before changing security behavior. A mock or fixture replay does not qualify a new deployment.

| Task | Procedure / entry point | Scope |
| --- | --- | --- |
| Locked checkout and package loading | [Required contributor checks](../../CONTRIBUTING.md): `npm ci --ignore-scripts`, `npm run check`, `npm run smoke`, `npm run smoke:packages` | Node 24; tests plus native login/load and isolated tarballs. Smokes can download packages; loading is not verifier qualification. |
| Local Markdown files and heading links | `node scripts/check-markdown-links.mjs` ([checker](../../scripts/check-markdown-links.mjs)) | Git-tracked Markdown, excluding code examples; local inline/reference destinations and Markdown headings/explicit anchors. External URLs, renderer-specific extensions and historical GitHub line anchors are outside this check. |
| CPU/release/artifact qualification | [Public-build helper run and fixture instructions](../../tools/tinfoil-public-build/README.md#run), [fixture provenance](../../tools/tinfoil-public-build/testdata/README.md) | Fresh nonce, signed release/build/freshness and authenticated boot/OCI/runtime inputs; standalone CPU success does not qualify GPU or serving custody. |
| NVIDIA local appraisal and negative tests | [Verifier checks](../../tools/nvidia-verifier/README.md#checks), [check script](../../scripts/check-nvidia-verifier.ts) | Expected NVIDIA rejection codes and authentic positive controls; no credentials or inference. Delivery failures cannot stand in for policy rejection. |
| Build and reproduce packaged verifiers | [Pinned sources and build recipe](../../tools/nvidia-verifier/README.md), [reproducibility](../../tools/nvidia-verifier/README.md#reproducibility), [CI rebuild workflow](../../.github/workflows/wasm-verifiers.yml) | Follow the mandated WASM artifact workflow for source/pin changes. Ordinary documentation checks do not reproduce binaries. |
| Actual Pi provider qualification | [Opt-in live harness](../../scripts/live-pi.ts), [root command examples](../../README.md#validation) | Synthetic capped inference, native login/stored-key precedence, tools, reasoning and cancellation. Inspect harness options and record the exact command, commit and runtime. Live inference may be billed. |
| Chutes catalog/evidence sampling | [Attestation harness](../../scripts/live-chutes-attestation.ts), [validation and fixture instructions](../chutes-validation.md) | Discovery/evidence only; no inference. Per-model observations do not authorize future instances. |
| Tinfoil discovery / evidence | [Catalog harness](../../scripts/live-catalogs.ts), [worker harness](../../scripts/live-tinfoil-workers.ts), [attestation harness](../../scripts/live-tinfoil-attestation.ts) | Non-inference observations; discovery is untrusted delivery and every inference requires fresh admission. |

Use synthetic prompts for live checks, load credentials only into the needed process, and keep secrets, raw evidence and transcripts outside public logs and commits. Supply private fixtures when available; report skips explicitly. Cancellation at the response-consumption barrier proves local abort/acknowledgement, not remote generation-stop timing. Add new outcomes using the [evidence-record requirements](../evidence/README.md#recording-and-maintaining-observations).
