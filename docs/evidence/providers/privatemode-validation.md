## Request boundary

`createPrivatemodeProvider` registers one mesh route through core `assessRoute`. Discovery's potential levels filter models; actual levels are returned only after authentication succeeds. Stricter policies stop before bootstrap. Local manifest admission and its durable change record precede the credentialed bootstrap. Every request gets a new worker, nonce, verifier and secret exchange; no cached quote or deployment secret extends admission.

The worker loads only digest-checked bytes from `privatemode-ai@1.58.0`: Go WASM, its runtime glue, bridge and errors module. This is a locally trusted verification dependency. It invokes the low-level `initialize`/`updateSecret`/`streamChatCompletions` methods, without importing the high-level mismatch handler. The worker's fetch delegates to a fixed-path, HTTPS-only main-process boundary; no CDN, NRAS, proxyless, redirect or repeat inference route is available to that SDK. The separately selected logged-CDN policy fetches only a manifest without credentials or content.

The Contrast verifier authenticates the CPU quote, manufacturer collateral, nonce, reference values, manifest/mesh-CA report-data binding and policies. The wrapper and Coordinator document reject unknown or case-aliased fields so the JavaScript status decoder and Go verifier cannot select different field values. pi-tee additionally requires one byte-identical manifest and a unique policy-hash set exactly equal to its admitted `Policies`. Thus an extra, omitted or duplicated component fails before secret exchange. The secret client authenticates a mesh-CA certificate chain and a signature over the fresh hybrid HPKE key exchange. Shared deployment-key custody is disclosed; the certificate does not establish a fresh exclusive serving-worker identity.

The complete request JSON is encrypted by the SDK's OAE body protocol. Clear routing headers are restricted to the disclosed SDK metadata; the final core guard fixes the model, endpoint, authentication and payload after Pi hooks. The streaming decryptor releases authenticated frames only, and translates their JSON chunks into Pi SSE. Cancellation terminates the owned worker and cancels outstanding network readers. Bootstrap is bounded to 60 seconds, request plaintext to 16 MiB, and network responses to 32 MiB. The transport permits one dispatch before admission expires, and applies backpressure to both network reads and decrypted chunks.

## Ratings and trust

The exact manifest pins code/configuration policies for all admitted deployment-key recipients, including workloads outside the chosen model. A2 still trusts the provider's private behavior; source inspection of below-A1 code cannot establish verified downstream properties. The client checks the Coordinator's nonce and key binding but never receives fresh worker CPU reports or a complete signed serving-GPU set. H3/G3 therefore apply to the weakest recipients, irrespective of the Coordinator's individual result.

Authenticated Coordinator diagnostics use shared core TDX/SNP floor helpers. TDX uses the same `[3,1,2]` SVN and collateral-edition 20 floors as NEAR; SNP mirrors the existing Go verifier's Genoa/Turin CPU, ABI, firmware and current/launch TCB minima. The observed Genoa Coordinator reports build 1, below minimum 21. These diagnostics cannot promote the route: even an above-floor Coordinator would leave the worker closure H3. No NRAS appraisal or assembled GPU claim raises G3.

Operator-readable container logs and an OTLP relay that forwards raw bodies to an unattested collector without parsing or field allowlisting prevent a metadata-only handling claim. Below A1, downstream behavior is also unverified under the model. X3 discloses both limits rather than treating a known producer's metadata-only traces as an enforced runtime guarantee.

Hard-pin admission captures exact locally selected bytes and rejects every server mismatch. Explicit logged-CDN admission delegates the next choice of private-code bytes to Privatemode's CDN, saves each digest/source transition, then pins those exact bytes for the request. Neither mode silently retries a mismatch. The `ManifestAdmissionPolicy` interface permits future reproduced/public-log authorization; its output alone does not implement A1, build or review ratings.

The shipped manifest has SHA-256 `384a2137e534357d74392bf3940373ff49d309d91551376b5a7f828e372af42b`, downloaded from the public CDN and byte-identical to v1.58.0 on 2026-10-09. That hash fixes the bytes examined; the CDN itself is a mutable publisher, not public release authentication.

## Validation

The credential-free tests exercise native policy/catalog boundaries, immutable pins, fail-closed recording and explicit CDN changes. A fixture runs the actual pinned SDK with a synthetic offline secret, observes its encrypted outgoing bytes for prompt, reasoning, tool-result/schema/argument sentinels, and proves a plaintext response is rejected without a content callback. Offline initialization exists only in the test fixture, never the production transport.

On 2026-10-09, macOS ARM64 Node 26.10.0 passed the full native Pi suite for `gpt-oss-120b`, `glm-5.3-flash` and `glm-5.3`: stored-key precedence, streamed completion/usage, Unicode tool execution/follow-up, reasoning and cancellation at the response-consumption barrier. Bun 1.3.13 passed that suite for all three models; one GLM run missed the synthetic output marker and passed on retry. Bun additionally passed abort after a live GPT text delta without a consumption barrier. Each admitted model observed A2/H3/G3/X3. Authenticated live negatives rejected wrong nonce, swapped mesh key, replayed evidence, an extra/duplicated policy, a byte-changed manifest, a case-shadowed document and a changed secret-exchange signature with **zero inference requests**. No raw quotes, credentials or provider payloads are committed. Live availability is separate from these security levels.

The capped [Pi harness](https://github.com/ariofrio/pi-tee/blob/fa5e1547d4a99a8f40b0279f08aa24f9bcaa03b9/scripts/live-pi.ts) and [live attestation negatives](https://github.com/ariofrio/pi-tee/blob/fa5e1547d4a99a8f40b0279f08aa24f9bcaa03b9/tests/privatemode-live.test.ts) require the API key. A separate `--cancel-stream` run checks local abort after a text delta; neither cancellation test measures remote generation-stop timing. CI uses no private key and skips live tests.

Independent implementation review belongs to the parent provider-integration review before merge. This branch adds one generic core dependency commit for floor helpers; the provider, manifest, SDK loading and network enforcement are package-local.
